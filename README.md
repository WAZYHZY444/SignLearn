# SignMelody：汉语手指字母学习器

一个基于 MediaPipe + PyTorch 的汉语手指字母学习工具。输入拼音，系统展示标准指式，用户对着摄像头模仿，模型实时判定对错。

## 项目背景

汉语手指字母是听障人群学习汉语的基础工具，但初学者面临两个问题：

1. 不知道标准指式长什么样
2. 没有人纠正自己比得对不对

SignMelody 尝试解决这两个问题：**先教标准指式，再实时判定对错**。

## 功能

### 学习模式
- 输入拼音（如 `zhang`）
- 系统逐字母拆解（`zh → a → ng`）
- 展示每个字母的标准指式图和文字说明
- 支持“上一个/下一个”切换

### 练习模式
- 系统随机给一个目标字母
- 用户对着摄像头比出指式
- 模型实时识别，给出反馈：
  - 正确
  - 识别错误，提示实际识别结果

## 技术架构

- **手部关键点检测**：MediaPipe Hands（21 个关键点）
- **分类模型**：MLP（70 维输入 → 30 类输出）
- **界面**：Gradio
- **训练环境**：PyTorch + Anaconda

## 数据集

- **来源**：自己采集
- **规模**：30 个字母，每个 100-200 个样本，共 4000+ 样本
- **采集方式**：MediaPipe 提取手部 21 个关键点坐标，存为 `.npy` 文件
- **类别**：26 个单字母（a-z）+ 4 个双字母（zh, ch, sh, ng）

## 模型

- **输入**：70 维（63 维关键点坐标 + 7 维手工特征）
- **结构**：70 → 256 → 128 → 30
- **准确率**：99.40%
- **手工特征**：
  - 食指指尖到中指指尖的距离
  - 食指和中指的 x/y 差
  - 食指和中指的夹角
  - 拇指指尖到手腕/食指指尖/食指根部的距离

## 遇到的问题和解决方案

### 问题 1：MediaPipe 1.0.1 和 Python 3.8 不兼容
- **报错**：`'type' object is not subscriptable`
- **解决**：降级到 MediaPipe 0.10.9

### 问题 2：H 和 X 混淆
- **原因**：H 和 X 的区别在“中指是否搭在食指上”，但这个差异在原始 63 维坐标里很小
- **解决**：加入“两指指尖距离、x/y 差、夹角”4 个特征，模型能学到交叉信息

### 问题 3：B 和 U 混淆
- **原因**：B 和 U 的区别在“拇指位置”，模型从原始坐标里学不到
- **解决**：加入“拇指指尖到手腕/食指指尖/食指根部的距离”3 个特征
